# Воины Эпох

Коллекционная игра-крутилка для Telegram Mini App. Игрок открывает карточки воинов разных эпох, собирает альбом, сливает повторки, делает крафт, сражается, торгует с другими игроками на рынке.

Игра работает в двух режимах:

- **Без сервера** (если в `game.js` пустой `API_URL`): прогресс хранится в браузере, рынок изображают боты. Удобно для показа и проверки.
- **С сервером** (Cloudflare Worker + база D1): каждая карточка существует в одном экземпляре на всю игру, рынок между настоящими игроками, честные бои с друзьями. Шансы, номера и деньги считает только сервер.

## Что есть в игре

- **32 воина** в серии 1: от ополченца до сёгуна и Мерлина, включая женщин-воинов и мифологию (Медуза, Минотавр, Анубис). Портреты нарисованы кодом (SVG).
- **Две оси редкости:** сам воин (обычный → мифический) и отделка (обычная, блестящая, голограмма, золотая, ошибка печати).
- **Ограниченный тираж** отделок: блестящих по 1000, голограмм по 100, золотых по 10, «ошибка печати» одна.
- **Уникальный номер** у каждой карточки и красивые номера с множителем цены (000 001, 777 777, лесенки, зеркальные и так далее).
- **Характеристики** (атака, броня, скорость, выносливость, боевой дух) разные у каждого экземпляра.
- **Эффектное открытие:** свечение и тряска до переворота, лучи и затемнение на редких, прокрутка номера цифра за цифрой, счётчик цены, конфетти, звук.
- **3 бесплатные прокрутки каждые 4 часа** (новичку на старте 5), плюс прокрутки за задания, серию входов и достижения.
- **Гарантия:** если 30 карточек подряд без эпической, следующая будет эпической или лучше.
- **Серия входов** на 7 дней, на 7-й день гарантированная эпическая карточка.
- **Задания дня** и **достижения**.
- **Бой в три раунда:** в первом раунде характеристику выбираешь ты, во втором соперник, в третьем она выпадает случайно. Режимы «на интерес» и «на карточку».
- **Уровни воинов** (до 10): опыт за бои, босса и походы, +4% ко всем характеристикам за уровень.
- **Босс недели — Змей Горыныч:** отряд из трёх воинов, 3 удара в день, критические удары, награды за каждые 25% урона.
- **Походы:** 3 места, 4 направления от 1 минуты до 8 часов, добыча: опыт, деньги, прокрутки, шанс на новую карточку.
- **Крафт:** отдаёшь карточки, выбираешь цель, крутишь колесо с шансом.
- **Слияние:** 3 одинаковых карточки → 1 с отделкой выше.
- **Альбом**, **коллекция**, **витрина** из трёх лучших карточек.
- **Рынок:** выставляешь свою карточку по своей цене, другие игроки покупают. Комиссия 5%, до 5 лотов одновременно. Быстрая продажа системе — 85% оценки.
- **Лавка — на что тратить деньги:** тренер, зелье ярости для босса, карта похода, рамки для карточек, амулет удачи в крафте.
- **Друзья:** ссылка на свою витрину и вызов на бой по ссылке. С сервером в ссылке только номер игрока или карточки, а сама карточка берётся с сервера, поэтому подделать её нельзя.
- **«Похвастаться»** выпавшей карточкой и вибрация телефона внутри Telegram.
- **Рефералы:** у каждого игрока своя ссылка `t.me/VoinyEpohBot?startapp=r_<id>`. За каждого нового игрока, который зашёл по ней, пригласивший получает +5 прокруток. Повторные входы и приглашение самого себя не считаются.
- **Подписка на канал @Voiny_official:** +5 прокруток один раз. Сервер проверяет подписку через Telegram, поэтому **бот должен быть администратором канала**.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html`, `style.css` | страница и стили |
| `rules.js` | **правила игры**: воины, отделки, шансы, номера и все действия. Один и тот же файл работает в браузере и на сервере |
| `game.js` | интерфейс: рисунки, анимации, кнопки. В начале файла настройки `API_URL` и `BOT_LINK` |
| `server/server.js` | сервер: проверка входа из Telegram, база, рынок, друзья |
| `server/schema.sql` | таблицы базы данных |
| `server/worker.js` | собранный сервер (rules.js + server.js) — именно его вставляешь в Cloudflare |
| `server/local-test.mjs` | проверка сервера у себя на компьютере без Cloudflare |
| `tools/build_worker.py` | собирает `server/worker.js` после изменений в правилах или сервере |
| `tools/bundle.py` | собирает игру в один файл `dist/single.html` |

**Важно:** если меняешь `rules.js` или `server/server.js`, запусти `python3 tools/build_worker.py` и заново вставь `server/worker.js` в Cloudflare. Иначе сервер и игра будут жить по разным правилам.

## Как включить сервер (один раз, минут 15)

Всё делается в панели Cloudflare в браузере, как с воркером ATOM.

1. **База данных.** Открой dash.cloudflare.com → Storage & Databases → **D1** → **Create database**, имя `voiny-epoh`. Открой базу → вкладка **Console** → вставь весь текст из `server/schema.sql` → **Execute**.
2. **Воркер.** Workers & Pages → **Create** → **Create Worker**, имя `voiny-epoh` → **Deploy**. Затем **Edit code**, выдели всё, вставь содержимое `server/worker.js` → **Deploy**.
3. **Привязка базы.** В воркере: Settings → **Bindings** → **Add** → **D1 database**. Variable name: `DB`, база: `voiny-epoh` → Save.
4. **Токен бота.** Settings → **Variables and Secrets** → **Add** → тип **Secret**, имя `BOT_TOKEN`, значение — токен бота из @BotFather (команда `/token`). Сервер проверяет им, что игрок пришёл именно из Telegram.
5. **Тестовые кнопки (по желанию).** Там же добавь переменную `TEST` со значением `1`, чтобы работали «+3 прокрутки» и ускорение походов. Перед запуском для игроков удали её.
6. **Проверка.** Открой адрес воркера (вида `https://voiny-epoh.твоё-имя.workers.dev`) в браузере. Должно показать `"server":"работает"`.
7. **Подключи игру.** В `game.js` пропиши этот адрес в `API_URL` и ссылку на бота в `BOT_LINK`, залей на GitHub. Игра с сервером работает только при открытии через бота в Telegram.

## Как подключить к боту

1. **GitHub Pages:** Settings → Pages → ветка `main`, папка `/ (root)` → Save. Адрес игры: `https://prostovladon-prog.github.io/kruti-kvartiru-/`.
2. **Кнопка в боте:** @BotFather → бот → Bot Settings → Menu Button → ссылка на игру.
3. **Ссылки для друзей:** @BotFather → бот → Bot Settings → **Configure Mini App** → включи и укажи ту же ссылку. Тогда ссылки вида `t.me/бот?startapp=...` (витрина, вызов на бой) открываются прямо в игре.

## Проверка у себя

Игра без сервера: `python3 -m http.server 8000` в папке проекта и открой `http://localhost:8000`.

Сервер (нужен Node 22): `python3 tools/build_worker.py && node server/local-test.mjs`. Тест сам создаёт базу в памяти и проверяет вход через Telegram, открытия, уникальность номеров, рынок между двумя игроками (включая двух покупателей одновременно), бои, босса, походы, крафт и бой с другом.

## Важные правила

- **Никаких чужих брендов и персонажей** (Marvel, Гарри Поттер, клубы, футболисты, логотипы). Только свои воины и исторические или мифологические образы.
- **Аудитория 15–25, есть несовершеннолетние.** Платные прокрутки со случайным выпадением и вывод за реальные деньги — это азартная игра. Прокрутки бесплатные, деньги в игре только игровые, за Telegram Stars — только косметика.
- В рекламе показывать настоящие выпадения или подписывать, что это пример.
