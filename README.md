# Воины Эпох

Коллекционная игра-крутилка для Telegram Mini App. Игрок открывает карточки воинов разных эпох, собирает альбом, сливает повторки, делает крафт и устраивает бои «у кого больше».

Сейчас это **прототип без сервера**: весь прогресс хранится в браузере игрока (localStorage). Чтобы карточки были по-настоящему в одном экземпляре на всю игру, нужен бэкенд (план ниже).

## Что уже есть

- **32 воина** в серии 1: от ополченца до сёгуна и Мерлина, включая женщин-воинов и мифологию (Медуза, Минотавр, Анубис). Портреты нарисованы кодом (SVG).
- **Две оси редкости:** сам воин (обычный → мифический) и отделка (обычная, блестящая, голограмма, золотая, ошибка печати).
- **Ограниченный тираж** отделок: блестящих по 1000, голограмм по 100, золотых по 10, «ошибка печати» одна.
- **Уникальный номер** у каждой карточки и красивые номера с множителем цены (000 001, 777 777, лесенки, зеркальные и так далее).
- **Характеристики** (атака, броня, скорость, выносливость, боевой дух) разные у каждого экземпляра.
- **Эффектное открытие:** свечение и тряска до переворота, лучи и затемнение на редких, прокрутка номера цифра за цифрой, счётчик цены, конфетти, звук.
- **3 бесплатные прокрутки каждые 4 часа**, плюс прокрутки за задания, серию входов и достижения.
- **Гарантия:** если 30 карточек подряд без эпической, следующая будет эпической или лучше.
- **Серия входов** на 7 дней, на 7-й день гарантированная эпическая карточка.
- **Задания дня** и **достижения**.
- **Бой в три раунда** против случайного соперника: в первом раунде характеристику выбираешь ты, во втором соперник, в третьем она выпадает случайно. Побеждает тот, кто выиграл два раунда. Режимы «на интерес» и «на карточку».
- **Уровни воинов** (до 10): опыт за бои, босса и походы, каждый уровень даёт +4% ко всем характеристикам.
- **Босс недели — Змей Горыныч:** отряд из трёх воинов, 3 удара в день, критические удары, награды за каждые 25% урона.
- **Походы:** 3 места, 4 направления от 1 минуты до 8 часов, воин возвращается с опытом, деньгами, прокрутками и шансом на новую карточку.
- **Крафт:** отдаёшь карточки, выбираешь цель, крутишь колесо с шансом.
- **Слияние:** 3 одинаковых карточки → 1 с отделкой выше.
- **Альбом**, **коллекция**, **витрина** из трёх лучших карточек.
- **«Похвастаться»:** отправка выпавшей карточки другу через Telegram.
- **Витрина для друга:** ссылка с твоими тремя лучшими карточками. Друг открывает её и видит витрину, а она сохраняется у него в списке «Друзья».
- **Бой с другом:** вызов по ссылке твоим воином по выбранной характеристике. Друг выбирает своего воина, видит результат и может отправить вызов в ответ.

Пока сервера нет, данные карточки передаются прямо внутри ссылки (параметр `startapp`). Это работает, но такую ссылку можно подделать, поэтому бой с другом идёт только «на интерес». Чтобы ссылки открывались прямо в мини-приложении, в @BotFather включи Main Mini App (Bot Settings → Configure Mini App) и пропиши `BOT_LINK` в `game.js`.
- Вибрация телефона (HapticFeedback) внутри Telegram.

Кнопка **«+3»** вверху даёт тестовые прокрутки. Перед запуском для игроков её нужно убрать.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка страницы |
| `style.css` | все стили |
| `game.js` | вся логика игры: воины, редкость, номера, рисунки, бои, крафт |
| `tools/bundle.py` | собирает всё в один файл `dist/single.html` |

Главные настройки в начале `game.js`: список воинов `HEROES`, отделки `FIN`, шансы. Ссылка на бота — константа `BOT_LINK`.

## Как запустить у себя

Просто открой `index.html` в браузере. Или запусти локальный сервер в папке проекта:

```
python3 -m http.server 8000
```

и открой `http://localhost:8000`.

## Как выложить и подключить к боту

1. **Включи GitHub Pages:** в репозитории открой Settings → Pages, в поле Source выбери `Deploy from a branch`, ветку `main` и папку `/ (root)`, нажми Save. Через минуту игра будет доступна по адресу `https://prostovladon-prog.github.io/kruti-kvartiru-/`.
2. **Создай бота** в @BotFather командой `/newbot` (если ещё нет).
3. **Подключи Mini App:** в @BotFather выбери бота → Bot Settings → Menu Button → укажи ссылку на GitHub Pages. Или создай отдельное приложение командой `/newapp`.
4. **Пропиши ссылку на бота** в `game.js` в константе `BOT_LINK` (например `https://t.me/voiny_epoh_bot`), чтобы кнопка «Похвастаться» вела к тебе.

## Что дальше: бэкенд

Без сервера каждый игрок живёт в своём мире. Для настоящей игры нужен сервер. Предлагаемый стек, как в ATOM:

- **Cloudflare Workers** для API.
- **D1** (база): игроки, карточки, тиражи, история сделок.
- **Durable Objects** для прокруток, крафта и покупок, чтобы два игрока не получили один и тот же экземпляр и один номер.
- **Проверка входа** через `initData` Telegram на сервере.
- **Шанс и номер считаются только на сервере**, иначе их подделают.

Что станет возможным с сервером:

1. Настоящая уникальность: «золотая 5 из 10» и «№ 777 777» существуют один раз на всю игру.
2. Рынок между игроками, аукционы, обмен, предложение цены владельцу.
3. Бой с другом по ссылке и реальные соперники.
4. Рефералы: прокрутки за приглашённых друзей.
5. Рейтинги и витрина в профиле, которую видят другие.
6. Сезоны: серия 2 «Будущее» (киберсамураи, роботы), события с лимитированными карточками.

## Важные правила

- **Никаких чужих брендов и персонажей** (Marvel, Гарри Поттер, клубы, футболисты, логотипы). Только свои воины и исторические или мифологические образы.
- **Аудитория 15–25, есть несовершеннолетние.** Платные прокрутки со случайным выпадением и вывод за реальные деньги — это азартная игра. Прокрутки бесплатные, за деньги (Telegram Stars) — только косметика.
- В рекламе показывать настоящие выпадения или подписывать, что это пример.
