# Мальчик-воин · Серия 1: «Портал» (сохранено 10.11)
Формат: Влад в углу говорит с главным героем Тимом; в конце выбор, голосование только в игре.
0–3 Пацан: «Ха! Воин с палкой!» / Влад: «Эй, малой! Да, ты. Хочешь стать настоящим воином?» / Тим: «Кто это сказал?!»
3–9 Влад: «Я. Сверху. Неважно. Смотри: у меня есть портал во все эпохи». / Тим: «А… это не опасно?» / Влад: «Очень опасно. Поэтому и интересно».
9–16 Тим падает на арену: «Где я?!» / Влад: «Похоже, на арене. И, кажется, ты не один».
16–24 Спартанец: «Малыш. Пойдёшь со мной — научу никогда не отступать». / Самурай: «Пойдёшь со мной — научу побеждать без единого удара». / Тим: «Влад… кого выбрать?» / Влад: «Ох… Это решать не мне».
24–30 Влад: «Тим ждёт вашего решения! Спартанец или Самурай? Голосуйте в игре, ссылка в профиле. Что выберет большинство, то будет в следующей серии». / Тим: «Только быстрее, они страшные!»
Надпись: «⚔️ СПАРТА или 🗡 ЯПОНИЯ? Голосуй в игре · Воины Эпох». В игре: голосование + 1 прокрутка за голос.
