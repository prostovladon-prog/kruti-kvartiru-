# Карта дня: Сын сёгуна — 22 ноября 2026

Владелец согласовал игровой предпросмотр, оценку 1 311 111 🪙 и цену покупки 3311 ⭐. Номер 111111 занят картой «Основатель», поэтому покупной экземпляр имеет №111112. После первой публикации владелец уточнил тираж: **один экземпляр за звёзды и отдельный экземпляр из Особого прокрута**. Покупка не закрывает выпадение. Для второго экземпляра используется первый свободный номер из 111113–111119. Событие заканчивается 23 ноября в 01:00 по Минску. С 00:00 шанс в Особом прокруте становится 100%, если экземпляр из прокрута ещё не выбит. До этого шанс 0,3% за Особый прокрут.

Иллюстрация встроена в `game.js` как SVG, взмах катаны и окружающие эффекты анимируются в карточке. Фото поста снято через настоящий игровой `fillFace`: `assets/day-son-shogun.jpg`. После ручного обновления VPS серверный `sonReleaseTick` отправляет пост с фото в канал один раз и исправляет уже отправленный пост, если там указана прежняя общая квота. Фактическую отправку или правку нужно проверить в канале.

Выдача обоими способами использует `dayCardMake`, чтобы закрепить номер, характеристики и оценку. Для сохранения тиража после продажи карты системе в `kv` записываются отдельные ключи `dc:claimed:<h>:dbuy` и `dc:claimed:<h>:dspin` внутри той же пачки, что и карточка. Старая запись `dc:claimed:<h>` читается с указанием способа получения: уже купленный экземпляр не блокирует экземпляр из прокрута. Особый прокрут без доступной карты не расходуется.

Проверено локально: синтаксис JS, `git diff --check`, сборка `server/worker.js`, фиксированные номер/оценка/характеристики для обоих способов, окно 21:00–01:00 Минск, игровой экран карты дня и реальный шаблон карточки через headless Chrome. Требуется ручное обновление VPS владельцем командой `voiny-update`; продакшен база и реальная доставка поста локально не проверялись.
