# Карта дня: Сын сёгуна — 22 ноября 2026

Владелец согласовал игровой предпросмотр, оценку 1 311 111 🪙, цену покупки 3311 ⭐ и выпуск одной карты с номером 111112. Номер 111111 занят картой «Основатель», поэтому не используется повторно. Событие открывается после обновления VPS и заканчивается 23 ноября в 01:00 по Минску. С 00:00 шанс в Особом прокруте становится 100%, если единственный экземпляр ещё доступен. До этого шанс 0,3% за Особый прокрут. Звёздная покупка и выпадение конкурируют за один экземпляр; первый подтверждённый способ выдачи выигрывает.

Иллюстрация встроена в `game.js` как SVG, взмах катаны и окружающие эффекты анимируются в карточке. Фото поста снято через настоящий игровой `fillFace`: `assets/day-son-shogun.jpg`. После ручного обновления VPS серверный `sonReleaseTick` отправляет пост с фото в канал один раз, с повтором при временной ошибке Telegram. Фактическую отправку нужно проверить в канале.

Выдача обоими способами использует `dayCardMake`, чтобы закрепить номер, характеристики и оценку. Для сохранения тиража после продажи карты системе в `kv` записывается `dc:claimed:<h>` внутри той же пачки, что и карточка. Запись уникальна; одновременные попытки не создают второй экземпляр. Особый прокрут без доступной карты не расходуется.

Проверено локально: синтаксис JS, `git diff --check`, сборка `server/worker.js`, фиксированные номер/оценка/характеристики для обоих способов, окно 21:00–01:00 Минск, игровой экран карты дня и реальный шаблон карточки через headless Chrome. Требуется ручное обновление VPS владельцем командой `voiny-update`; продакшен база и реальная доставка поста локально не проверялись.
