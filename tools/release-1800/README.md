## 🐉 Земля драконов (карта мира)
- На карте мира новая вкладка «🐉 Земля драконов» — вулканический остров из 10 логов (id 50–59 в MAP_R).
- Логова захватывают и держат только драконы: бой как на арене (мощь, стихия, тактика).
- Свободное логово сторожит дикий дракон (~72–102% твоей мощи), бой с ним не тратит атаку.
- Чужое логово: тратит 1 атаку карты, щит 3 ч, хранитель устаёт −7% за каждую отбитую атаку (до −35%).
- Один дракон = одно логово (не входит в лимит 3 обычных регионов). Доход логова +300 🪙/+50 💠 в час, 🐲 Трон Драконов — ×2.
- Сила хранителя = текущая сила дракона хозяина. Дракон никуда не уходит, арена работает как раньше.
